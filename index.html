02 / 开始使用

播放器与音乐，
由你自己掌握。

  1. 1

    安装 Jusic

    不确定手机架构时下载通用版；近年的安卓手机可以选择体积更小的 ARM64 版。

  2. 2

    准备私人内容包

    使用你自己合法获得的标准音频和同名 LRC 歌词，在电脑上生成 `.jusicpack`。

  3. 3

    选择并导入

    进入“设置 → 私人曲库 → 选择内容包”，等待解压和逐首校验完成。

  4. 4

    开始聆听

    按专辑、热度或收藏浏览，也可以直接使用语音说出想听的歌。

03 / 常见问题

下载前需要知道

为什么安装后没有歌曲？

Jusic 不内置或在线分发歌曲。安装后需要导入你自己制作并保存的 `.jusicpack` 内容包。

通用版和 ARM64 版怎么选？

不确定时选择通用版。近年小米、红米、华为、荣耀、OPPO、vivo 等主流手机通常可以使用 ARM64 版。

检查更新为什么有时连接失败？

更新清单和安装包托管在 GitHub，网络无法访问 GitHub 时会检查失败，恢复可用网络后重新检查即可。

Windows 版本在哪里？

当前 Windows 专属版会把私人曲库直接封装进安装包，因此不公开发布含歌曲的安装包。源码仍保留 Windows 本地构建能力。
